🎮 Tic Tac Toe

DSA-Based AI Game

🧠 DSA Concepts Used

📦 Array Stores the 3×3 game board
📚 Stack Handles Undo operations
📋 Queue Tracks moves using FIFO
🗺️ Map Maintains the scoreboard
🔎 Linear Search Searches game history
🔄 Recursion Explores game states
↩️ Backtracking Restores temporary states
🤖 Minimax Makes AI decisions
✂️ Alpha-Beta Prunes unnecessary branches
📊 Complexity Analyzes time and space

Built as a DSA & Placement Preparation Project
